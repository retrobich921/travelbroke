# TravelBroke — факты для презентации

## Что делает сервис

TravelBroke не просит человека назвать пункт назначения. Пользователь задаёт
город отправления, дату, доступный бюджет, время в пути и виды транспорта;
сервис показывает на карте реальные направления, которые подтверждает Туту.

## Как устроен поиск

1. API резолвит город отправления и формирует географически сбалансированный
   список кандидатов.
2. Для каждой пары «откуда → куда» вызывает `search_multitransport` MCP Туту.
   Вызовы идут параллельно, максимум по 8 одновременно.
3. В карту попадают только варианты с известной ценой. Расписание без цены
   остаётся доступным в карточке, но не выдаётся за бесплатную поездку.
4. Для дорогих или недостижимых прямых направлений сервис дополнительно
   проверяет составные пути через хабы. Весь маршрут ограничен тремя
   пересадками и проходит проверку на реальный запас времени.
5. Ответ целиком уходит в браузер: фильтры бюджета и времени перестраивают
   карту мгновенно, без новых запросов к серверу.

## Мировое покрытие

- Географический каталог: около **34 000 городов в 252 странах**.
- Источник координат и мирового перечня — локальная база GeoNames; реальные
  транспортные предложения, даты и цены всегда подтверждаются MCP Туту.
- В каталоге сохраняется до **15 крупнейших городов** небольшой страны и до
  **50 крупнейших городов** большой страны.
- Россия включается в поиск полностью: дальние города, в том числе
  Владивосток и Хабаровск, не вытесняются ближайшими направлениями.

## Один поиск из Москвы

В текущей конфигурации проверяется до **380** направлений. После
географической дедупликации типичный пул из Москвы содержит **365 городов**:
все российские города каталога и международные направления по квотам:

| Регион | Международных кандидатов |
|---|---:|
| Европа | 55 |
| Азия | 70 |
| Африка | 55 |
| Северная Америка | 50 |
| Южная Америка | 40 |
| Океания | 25 |

Квоты важнее географической близости: поэтому поиск не ограничивается
Россией, СНГ и Европой. В пуле есть, например, Каир, Лагос, Йоханнесбург,
Нью-Йорк, Лос-Анджелес, Торонто, Мехико, Сан-Паулу, Буэнос-Айрес, Сидней и
Окленд.

## Честное ограничение

Сервис не рисует фиктивные рейсы. Если Туту не отдаёт продаваемый маршрут на
выбранную дату, с активными видами транспорта и известной ценой, город не
появится как доступное направление. Первый широкий поиск требует больше
запросов; повторные запросы ускоряет недельный дисковый кэш.
