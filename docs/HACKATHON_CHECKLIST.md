# Готовность TravelBroke к Туту хакатону

Этот файл связывает требования из `../tutu_hack/BRIEF.md` с тем, что можно
проверить в репозитории и на демо. Он нужен и команде перед защитой, и
автоматической проверке кода.

| Критерий | Что показывает TravelBroke | Где проверить |
|---|---|---|
| UX/UI, 20 | Инвертированный поиск: пользователь задаёт ограничения, а карта отвечает «куда могу». Фильтры работают без перезагрузки результатов. | Главный экран, карта, `web/src/` |
| Функционал, 15 | Авиа, поезд, автобус, электричка; бюджет, время, даты, пассажиры, возврат, страны, до 3 пересадок. | `src/travelbroke/reach.py` |
| Соответствие теме, 10 | Каждый показанный маршрут/цена/дата — из `search_multitransport` MCP Туту. | `src/tutukit/client.py`, `src/travelbroke/reach.py` |
| Документация, 10 | README, руководство пользователя, архитектура, ADR и OpenAPI `/docs`. | `README.md`, `docs/` |
| Инновационность, 10 | Не чат и не голос: карта досягаемости на всех видах транспорта плюс проверяемые стыковки. | `README.md`, демо карты |
| Стабильность, 10 | Кэш MCP, режим replay, строгая валидация резолвинга городов, CI, Docker health-check. | `src/tutukit/cache.py`, `.github/workflows/` |
| Архитектура, 10 | Чёткие слои: FastAPI → домен → MCP-адаптер. | `docs/ARCHITECTURE.md` |
| Качество кода, 10 | Типы, ruff, mypy, pytest, воспроизводимая сборка `uv.lock`/`package-lock`. | `pyproject.toml`, `tests/`, CI |

## Честность данных

- Ссылка покупки создаётся только через `create_checkout_link` и ведёт на
  конкретный оффер. Общую страницу поиска вместо неё не открываем.
- Если Туту не вернул цену, интерфейс сообщает «Цена неизвестна», а не рисует
  ноль рублей.
- Если Туту зарезолвил введённый город как другой, направление отбрасывается:
  нельзя показать цену Санкт-Петербурга в точке Le Lamentin.
- Внутренние сегменты оффера отображаются на карте как пересадки; линия не
  выдаёт перелёт с пересадкой за прямой рейс.
- Внешние данные GeoNames/Nominatim используются только для координат и
  подсказок. Маршрут, дата, транспорт и цена подтверждаются Туту.

## Перед сдачей

1. Открыть ссылку на прототип в инкогнито и сделать один поиск.
2. Открыть [руководство пользователя](USER_GUIDE.md) без авторизации.
3. Убедиться, что репозиторий GitHub публичен, а Actions зелёные.
4. Выполнить команды из раздела «Проверка качества» в README.
5. Для питча подготовить URL с уже заданными фильтрами и записанный короткий
   fallback-ролик на случай недоступности картографических тайлов.
