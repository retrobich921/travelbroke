## Решения (ADR)

Записи о принятых архитектурных решениях: контекст, варианты, выбор и
последствия. Читаются в любом порядке.

| № | Решение | О чём |
|---|---|---|
| [0001](adr/0001-graph-over-pairwise-search.md) | Граф вместо попарного поиска | Почему составные маршруты ищутся по графу, а не перебором пар «откуда — куда» |
| [0002](adr/0002-client-side-filtering.md) | Фильтрация на клиенте | Почему матрица уходит в браузер целиком и ползунки не ходят на сервер |
| [0003](adr/0003-disk-cache-as-stability.md) | Дисковый кэш как устойчивость | Почему кэш здесь не оптимизация, а страховка демо |
| [0004](adr/0004-transfer-buffer.md) | Запас времени на пересадку | Откуда взялись 60 / +90 / +60 минут и почему стыковки впритык не показываются |

## Схема API

Генерируется FastAPI автоматически и всегда соответствует коду:

- `/docs` — интерактивный Swagger UI
- `/redoc` — читаемая справка
- `/openapi.json` — машинная схема

Локально доступны после `uv run uvicorn travelbroke.api:app`.
