# Деплой TravelBroke

Прототип должен быть доступен по ссылке до 21 августа включительно — судьи
пересматривают прототипы финалистов утром в пятницу. Поэтому хостим на своём
VPS, а не на бесплатном сервисе, который засыпает от простоя.

## Первый запуск на сервере

```bash
git clone https://github.com/retrobich921/travelbroke.git
cd travelbroke
docker compose up -d --build
```

Caddy сам получит сертификат Let's Encrypt для `79-137-248-221.sslip.io`.
Своё доменное имя не требуется: `sslip.io` резолвит имя вида `1-2-3-4.sslip.io`
в соответствующий IP.

Проверка: `curl https://79-137-248-221.sslip.io/api/health`

## Автодеплой

Workflow `.github/workflows/deploy.yml` при пуше в `main` подключается к серверу
по SSH и перезапускает контейнеры. Нужны секреты репозитория:

| Секрет | Значение |
|---|---|
| `VPS_HOST` | IP сервера |
| `VPS_USER` | пользователь SSH |
| `VPS_SSH_KEY` | приватный ключ в формате OpenSSH |
| `VPS_PATH` | путь к клону репозитория на сервере |

Добавить: `gh secret set VPS_HOST --body "..."` или через настройки репозитория.
